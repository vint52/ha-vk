# Security Policy

## Supported Versions

Security fixes are generally applied to the latest released version of `ha-vk`.
Please upgrade to the newest release before reporting whether an issue is still
reproducible.

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Send a private report to the maintainer using one of these options:

- GitHub Security Advisories, if enabled for the repository
- the maintainer's contact details listed on the GitHub profile

Include:

- a clear description of the issue
- the affected version
- reproduction steps or a proof of concept
- potential impact
- any relevant logs or screenshots with secrets removed

You can expect an acknowledgment within 7 days. After confirmation, the issue
will be fixed privately when possible and disclosed responsibly once users have
had a chance to update.

## Sensitive Data

Never include VK tokens, Home Assistant secrets, private URLs, or other
credentials in public issues, pull requests, or logs.
