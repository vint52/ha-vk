# Support

## Getting Help

- Read `README.md` or `README.en.md` for installation, configuration, and usage.
- Read `TOKENS.md` or `TOKENS.en.md` for VK token and ID setup.
- Check `CHANGELOG.md` to confirm whether the behavior changed in a recent release.
- Review existing issues before opening a new one.

## When Opening an Issue

Please include:

- Home Assistant version
- `ha-vk` version
- whether the problem affects `notify`, `ha_vk.send_message`, or `ha_vk.send_post`
- the expected result
- the actual result
- logs with tokens, URLs, and secrets removed

## What Not to Share

Do not post VK access tokens, wall tokens, Home Assistant secrets, or private
network details in issues, discussions, screenshots, or pull requests.
